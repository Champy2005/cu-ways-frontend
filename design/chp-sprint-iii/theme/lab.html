Component reference

Canonical defaults

What is shared

Actions, feedback, context-aware navigation, artwork, bars, selected icons, depth and motion all use components.mjs, recipes.css and generated tokens. The story composes these same pieces.

Depth, not a halo

Light uses gentle directional shadows. Dark uses a smaller tinted depth treatment with the same offsets and blur. Fills stay steady on hover; functional actions lift slightly. Compact tools stay flat.

Feedback, then actions

Neutral text, a semantic icon, and an accent rail explain the result. Retry and navigation live outside the banner, in an adjacent action group.

Navigation follows context

Above page content: quiet raw text. Inside a card: a bounded button treatment. Actual URL navigation remains an anchor; operations use buttons.

Intrinsic, not screenshot sizing

Text, controls and spacing use relative units. Thin edges, optical details and bounded blur use px. The sample composition is not a global page layout.

Parameter explanations · Component API · Design workflow · All canonical values
